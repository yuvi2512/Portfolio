# Yatish Joshi — portfolio

A Next.js portfolio for Yatish Joshi: React Server Components, an abstract React Three Fiber scene, motion, and a contact form validated by a Server Action.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Set `NEXT_PUBLIC_SITE_URL` when you deploy so the sitemap and robots file use the public address.
